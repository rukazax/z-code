# zcode-ru — русская локализация ZCode

Плагин ставит полный русский перевод интерфейса ZCode: каталог строк
(6999 ключей), меню приложения, диалоги обновления, шаблоны автоматизаций.
Перевод собран из всех публичных русификаторов ZCode и сверен с эталонным
`en-US` установленной версии.

## Как это работает

ZCode поставляется с двумя локалями — `zh-CN` и `en-US`. Новый язык добавить
нельзя (тип локали закрыт в коде), поэтому плагин перезаписывает значения
английского каталога внутри `resources/app.asar`:

- `out/renderer/assets/IntlProvider-*.js` — каталог интерфейса;
- `out/main/chunk-*.js` — нативное меню;
- `out/main/index.js` — диалоги обновления и «О программе»;
- `out/renderer/assets/styles-*.js` — шаблоны автоматизаций и серверные попапы.

Ключи остаются прежними, логика приложения не меняется, SHA-256 изменённых
файлов в заголовке asar пересчитываются — иначе Electron откажется их читать.

## Что выполнять

Все скрипты лежат в `assets/` плагина. В командах ниже `${CLAUDE_PLUGIN_ROOT}`
подставляется хостом.

**Проверить статус** (только чтение, без прав администратора):

```
powershell -NoProfile -ExecutionPolicy Bypass -File "${CLAUDE_PLUGIN_ROOT}/assets/check.ps1"
```

Выводит путь установки, версию приложения, наличие бэкапа и русский ли сейчас
интерфейс.

**Установить или обновить** (сборка от пользователя, установка запросит UAC):

```
powershell -NoProfile -ExecutionPolicy Bypass -File "${CLAUDE_PLUGIN_ROOT}/assets/apply.ps1"
```

Скрипт заново собирает патченный `app.asar` из **текущей** установки ZCode, то
есть после обновления приложения пересборка подхватывает новый каталог строк:
ключи, которых нет в переводе, остаются английскими, остальные переводятся.

**Вернуть оригинал:**

```
powershell -NoProfile -ExecutionPolicy Bypass -File "${CLAUDE_PLUGIN_ROOT}/assets/uninstall.ps1"
```

Восстанавливает `app.asar` из бэкапа
`%LOCALAPPDATA%\ZCodeRu\app.asar.backup`.

## Важные детали

- Запись идёт в `C:\Program Files\ZCode` — нужны права администратора, скрипты
  сами вызывают UAC. Если окно UAC не подтвердить, ничего не изменится.
- После установки пользователь должен **полностью** закрыть ZCode (трей →
  «Выйти») и открыть заново: в памяти остаются уже загруженные английские чанки.
- Если ZCode запущен, архив пишется поверх существующего файла — это штатный
  путь, перезапуск всё равно обязателен.
- Любое обновление ZCode возвращает оригинальный `app.asar`. Об этом же
  предупреждает SessionStart-хук плагина: если интерфейс снова английский,
  достаточно повторить установку.
- `.ps1`-файлы плагина обязаны оставаться в UTF-8 **с BOM**: PowerShell 5.1
  иначе прочитает кириллицу как ANSI и скрипт не разберётся.

## Состав

- `assets/translations/ru-RU.json` — каталог `ключ → русский текст`, 6999 строк;
- `assets/patch.js` — сборщик патченного архива (запускается через рантайм
  ZCode: `ELECTRON_RUN_AS_NODE=1`, `ELECTRON_NO_ASAR=1`);
- `assets/apply.ps1` / `install.ps1` / `uninstall.ps1` / `check.ps1` —
  оркестрация, установка с бэкапом, откат, диагностика.

## Если что-то пошло не так

- «Не найден установленный ZCode» — приложение стоит в нестандартном месте;
  скрипты ищут `C:\Program Files\ZCode` и `%LOCALAPPDATA%\Programs\ZCode`.
- «Каталог интерфейса не найден» — структура бандла изменилась в новой версии;
  нужно обновить `assets/patch.js` под неё.
- Интерфейс остался английским после установки — приложение не перезапускали.
- Ошибки установки пишутся в `%LOCALAPPDATA%\ZCodeRu\install.log`.
