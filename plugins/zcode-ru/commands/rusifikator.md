---
description: Русифицировать интерфейс ZCode (установить, обновить или откатить перевод)
---

Пользователь вызвал `/rusifikator`. Действуй по скиллу `zcode-ru` из плагина
`zcode-ru`.

1. Определи режим по тексту после команды: пусто — установка/обновление,
   `статус` или `status` — только проверка, `откат` или `rollback` — вернуть
   оригинал.
2. Для проверки запусти `assets/check.ps1` и перескажи результат человеческим
   языком: путь установки, версия, русский ли интерфейс, есть ли бэкап.
3. Для установки запусти `assets/apply.ps1` (нужен UAC), дождись завершения и
   сообщи итог: сколько строк переведено, что изменилось, нужно ли перезапустить
   ZCode.
4. Для отката запусти `assets/uninstall.ps1` (нужен UAC).
5. Не подменяй собой скрипты и не правь `app.asar` вручную: только
   `assets/*.ps1` и `assets/patch.js` из плагина.
6. Если скрипт упал, приведи текст ошибки из `%LOCALAPPDATA%\ZCodeRu\install.log`
   и назови причину.

Аргумент пользователя: $ARGUMENTS
