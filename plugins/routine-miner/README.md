# routine-miner — скилы из повторяющихся задач

Плагин ZCode, который находит твои типовые запросы, собирает их в скилы и
подставляет нужный скилл автоматически. Меньше повторных объяснений — меньше
токенов на задачи, которые уже решались.

## Зачем

Ты снова и снова объясняешь одно и то же: как подключить аккаунт, как собрать
релиз, как проверить папку проекта. Майнер видит повторы в истории, сводит их в
рутину и пишет `SKILL.md` с шагами из прошлых сессий. При похожем запросе хук
`UserPromptSubmit` вставляет короткий блок `<routine>` — агент открывает один
скилл вместо того, чтобы разбираться заново.

## Что внутри

| Файл | Назначение |
|---|---|
| `.zcode-plugin/plugin.json` | манифест, компоненты `skills` и `commands` |
| `commands/routine-miner.md` | слэш-команда `/routine-miner` |
| `skills/routine-miner/SKILL.md` | инструкции агенту: как майнить и что делать с рутиной |

Код майнера и хуков живёт в ctxdb — отдельном каталоге на машине:

```
node "C:\Users\er-ka\Documents\z-code\ctxdb\src\cli.mjs" routines <подкоманда>
```

Скиллы рутин: `C:\Users\er-ka\Documents\z-code\ctxdb\routines\<id>\SKILL.md`,
реестр — `...\ctxdb\routines\routines.json`.

## Использование

```
/routine-miner                — статус: рутины, повторы, топ
/routine-miner скан           — запустить майнер
/routine-miner проверить "..." — проверить распознавание
/routine-miner забыть <id>    — удалить рутину
/routine-miner открыть <имя>  — показать SKILL.md рутины
```

Или напрямую:

```powershell
node "C:\Users\er-ka\Documents\z-code\ctxdb\src\cli.mjs" routines status
node "C:\Users\er-ka\Documents\z-code\ctxdb\src\cli.mjs" routines scan
node "C:\Users\er-ka\Documents\z-code\ctxdb\src\cli.mjs" routines test "подключим github аккаунт"
```

## Как это работает

Запросы кластеризуются по эмбеддингам `multilingual-e5-small` (косинус ≥ 0.87,
минимум 2 запроса). Кластер превращается в `SKILL.md` и запись в
`routines.json`. Хук ищет рутину по нечёткому покрытию слов с порогом 0.38 и
вставляет блок `<routine>`: имя, статус, число повторов, суть и путь к скиллу.

Поиск и эмбеддинги локальные — **0 токенов**. Блок рутины — ~40-60 токенов
навигации (~130 с абсолютным путём), полный скилл читается только по
необходимости. Нет совпадения — нет вставки.

## Требования и ограничения

- Windows, установленный ctxdb с проиндексированной историей.
- Кластеру нужно минимум два похожих запроса: мало истории — мало скиллов.
- Стемминг наивный (общий корень 4 символа) — возможны редкие ложные
  совпадения.
- Статус `auto` значит, что скилл собран автоматически: при расхождении с
  реальностью агент уточняет, а не додумывает.
- Сложные процедуры лучше оформлять ручными скиллами — майнер их не заменяет.
