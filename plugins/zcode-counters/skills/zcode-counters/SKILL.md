# zcode-counters — счётчики токенов

## Суть

ZCode ничего не показывает про токены рядом с полем ввода, а данные уже есть —
`turn_usage`, `tool_usage`, в базе чатов. Плагин добавляет внутрь поля ввода живую
строку-счётчик как в DeepSeek Harness:

`21 ход · 459 шагов · 29 ток/с · Σ 70.8 млн · кэш 49.9% · $17.64 баланс · 89% лимиты`

## Как работает

1. Патчер (`assets/patch.cjs`) открывает `app.asar`, находит `out/renderer/index.html`
   и вставляет в конец `<script>`-оверлей (~1.6 КБ).
2. Оверлей — чистый DOM: прижимается к нижнему краю композера (резервирует 22 px снизу),
   `fetch("http://127.0.0.1:7717/usage/latest")` раз в ~400 мс, обновляет только значения.
   Никакого вмешательства в React.
3. Демона нет → fetch не отвечает → полоса просто скрыта. Отдельно демон ставить не нужно:
   обычно он уже есть от ctxdb, в нём и живёт счётчик.

## Показатели

| Показатель | Источник |
|---|---|
| Ходы | `turn_usage` по живой сессии |
| Шаги | `tool_usage` по живой сессии |
| Ток/с | `output_tokens / (completed_at − first_token_at)` последнего хода |
| Σ токенов | `computed_total_tokens` ходов (ввод + вывод) |
| Кэш % | `cache_read / (cache_read + input)` по живой сессии |
| Баланс | `balance.json` провайдера **выбранной модели** (`modelSelection` запроса) |
| Лимиты % | остаток `100 − usedPct` того же провайдера; нет квоты — прочерк |
| Полоса прячется | Ответ демона с `ok: true, empty: true` (нет активной сессии) |
